# DMAByDaylight

**DMAByDaylight** is a Dead by Daylight DMA companion. PCILeech / MemProcFS read, survivor and killer ESP, W2S, radar overlay. 2PC: DMA box plus game box.

## Getting Started
1. Download v3.5.
2. Extract `DMA-v3.4.zip` on the DMA box.
3. Attach the FPGA / PCILeech device.
4. Launch the overlay, then the game on the second PC.

## Troubleshooting

| Problem | Solution |
|---|---|
| Tool does not start | Run as Administrator |
| No entities | Check MemProcFS attach |
| Overlay offset | Recalibrate resolution in `proj/` |

## Requirements
Windows 10/11. DMA hardware + second PC.
